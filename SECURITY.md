# Security

Please report security issues to **security@lockally.com**. Include what you found, how to reproduce it, and what an attacker could do with it. Do not test against mailboxes or workspaces that are not yours.

We acknowledge reports, keep you updated while we fix them, and credit researchers on request. We do not run a paid bug bounty.

The hosted server is at `https://mcp.lockally.com/`. Message bodies it returns are untrusted third-party content: a report that an email can influence an AI client is in scope only where Lockally fails to label or flag it as described in the README.
